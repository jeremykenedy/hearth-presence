# Hearth Presence 1.0.0

A locally decoded, real burning fireplace with five photographed material
surrounds, normal-map lighting and remote-friendly controls.

## Upgrade guide

This is the first release. Android API 23+, OpenGL ES 2 and H.264 decoding are
required. Install hearth-presence.apk through the guided installer or Fire TV
Toolkit, open the app to configure it and select its DreamService. Future updates
must use the same package and signing certificate; update installs preserve
preferences. To remove, choose another screensaver then run the guided uninstall.
No migrations, accounts, runtime downloads or system-timer changes are required.

## Breaking changes

None. This is the initial public contract. The host settings schema is version 1.

## Major changes

- Genuine 1920x1080 wood-fire footage and a separate true gas-fire mode.
- Brick, white, classic timber, modern slate and marble materials with normal lighting.
- Frame width, frameless mode, burn speed, natural/amber/blue/violet grading, room light, ash and optional crackle.
- Very slow scene drift, per-setting random choices and randomize-on-start.
- Native DreamService, D-pad settings and a validated app-owned settings provider.

## Minor changes and fixes

- Local playback without network permissions, analytics or telemetry.
- Guided installer with fixed GitHub release hosts and SHA-256 verification.
- Animated light/dark banners and still alternatives for reduced motion.
- Java settings and installer logic each require 100% line and branch coverage.

## Verification and limits

See docs/VERIFICATION.md for the exact device matrix and completed checks.
Frame width changes the surround and reveal; it does not simulate individual
flames. Burn speed changes playback with pitch preserved. Linear gas is a
separate 32:9 crop of real gas footage. Gas footage includes a real mesh. Crackle audio is synthesized. Wood
footage is CC BY 3.0, gas footage is CC BY-SA 4.0, materials are CC0 and application
code is Apache-2.0. Native 4K, all vendor versions and long-term thermal behavior
are not established by emulator tests. No prior tag exists for comparison.
