# Hearth Presence 1.0.0

An offline fireplace screensaver with recorded fire, photographed surrounds and remote controls. The modern rectangular scene combines isolated recorded flame emission with an original steel burner and glass bed.

## Upgrade guide

This is the first public release, so there is no prior public tag or migration. Android API 23+, OpenGL ES 2 and H.264 decoding are required. No accounts, runtime downloads, database migrations, environment changes, asset builds or system-timer changes are needed.

Download `hearth-presence.apk` and `hearth-presence.apk.sha256` from this release. Verify the checksum and install with an explicit device serial:

```sh
shasum -a 256 -c hearth-presence.apk.sha256
python3 install.py --serial SERIAL --apk hearth-presence.apk
```

The guided installer can download and verify the latest stable release automatically with `python3 install.py --serial SERIAL`. Open Hearth Presence from the TV launcher, configure it, then use the remote's Open fireplace button to preview. Back returns to settings. Select its DreamService in the platform screensaver settings or through Fire TV Toolkit for idle use.

Existing development installations with the same package and production signer update in place and retain their preferences. The new linear flame-height setting defaults to medium. A different signer cannot update that installation; do not uninstall to work around a signing mismatch unless you intend to delete local settings. Keep a trusted signed APK for rollback. Selecting another screensaver provides a reversible fallback without removing Hearth or changing its preferences. Uninstalling deletes local preferences and requires `--uninstall`; scripted removal additionally requires `--yes --force`.

## Breaking changes

None. This is the initial public contract. The settings-provider endpoints expose eleven stable keys. Independent flame resizing is supported only for modern linear gas; recorded wood and traditional gas do not support that operation.

## Major changes

- Recorded 1920x1080 wood fire and traditional gas, plus a 1920x540 modern rectangular burner composite.
- Brick, white plaster, classic timber, modern slate and marble surrounds, with frameless mode.
- Frame width, linear flame height, burn speed, natural/amber/blue/violet grading, room light, ash, optional synthesized crackle and protective drift.
- Remote settings, per-option random values, randomize-on-start and a native protected DreamService.

## Minor changes and fixes

- Offline media, credits and full application license, without network permissions, analytics or telemetry.
- Guided installer with fixed trusted release hosts and SHA-256 verification.
- Animated desktop/mobile light/dark banners with static reduced-motion alternatives.
- Host settings and installer logic each enforce 100% line and branch coverage.

## Verification

The exact production APK is 69,011,424 bytes with SHA-256 `96067a79be86a0f29f034ee4bcc647e9da7195978b690a7d982f28a17b78278f`. Its signing certificate SHA-256 is `91128471b54e0c2cc28cb0400ebb5bd8e2b7f2509ba0b6d5ed0507f59752d5cf`.

Google TV API 34 checks cover the real renderer, frame and linear height controls, color, playback speed, remote credits and actual test-Dream with Back. Physical AFTDEC012E/API 30 checks cover in-place update preservation, remote Settings to Preview and Back, modern linear playback and frameless blue small/slow actual bound DreamService with Back. All eleven post-update preferences and five system values were restored exactly, and the TV returned to its prior asleep state. The physical modern recording lasts 19.741 seconds and passed independent moving review from start to end, including replay through the final boundary. A short SurfaceFlinger sample observed approximately 33.63 buffer presents per second; this is not a sustained renderer or decoded-video FPS claim.

## Limits and licenses

Explicit test-Dream behavior does not prove automatic idle activation across vendor configurations. Sustained temperature, power, all vendor versions and native 4K composition remain unverified. Drift does not guarantee prevention of image retention. Traditional gas footage includes a real safety mesh. Modern linear uses wood-combustion flame emission in a gas-burner depiction; it is not a photographed gas burner or fluid simulation. Crackle audio is synthesized.
