# Hearth Presence 1.1.0

Wood flame height now changes above a fixed log bed. Small and Large are bundled
1080p variants; Medium retains the original recording. This compatible feature
release also softens flame emission, revises the bezel and reduces the cost of
ash rendering. The modern linear fire remains the existing composite depiction.

## Upgrade guide

Upgrade the published 1.0.0/code 1 installation in place using the same package
and production signer. API 23+, OpenGL ES 2 and H.264 decoding remain required.
All eleven settings keys and choices are retained, with no migration, account,
runtime download, database, environment or timer change required. The existing
`flame_size` value now also controls wood; users who previously saved Small or
Large will see that height when they choose wood. Medium remains the original
recording. Traditional gas does not offer independent flame height.

Download `hearth-presence.apk` and `hearth-presence.apk.sha256` from this release:

```sh
shasum -a 256 -c hearth-presence.apk.sha256
python3 install.py --serial SERIAL --apk hearth-presence.apk
```

Alternatively, `python3 install.py --serial SERIAL` downloads and verifies the
latest stable release. Open Hearth Presence, select Wood and a flame height,
then use Open fireplace and Back to check the result. Select Hearth in your
platform's screensaver settings for idle use. The installer does not select a
Dream or change system timers. A signing mismatch must be investigated rather
than worked around by uninstalling and losing settings.

For a reversible fallback, select another screensaver and retain Hearth's
preferences. Android normally rejects a lower version-code APK; do not force a
downgrade or uninstall merely to revert the visual change. Keep the previous
trusted APK and a settings record for a deliberate recovery. Uninstalling removes
local preferences and requires the installer's explicit removal confirmation.

## Breaking changes

None. Package identity, signer, API floor, eleven provider keys and accepted
values are unchanged. The existing wood `flame_size` preference gains a visible
effect; no stored values are rewritten.

## Major changes

- Small, Medium and Large wood flame heights above unchanged logs and surrounds.
- Softer recorded flame emission and a revised firebox bezel.
- Pre-rendered height clips and point-rendered ash, avoiding the rejected
  full-screen flame-height processing path.

## Minor changes and fixes

- Actual code 7 physical screenshots, capture provenance and clearer video versus
  compositor timing qualifications.
- Remote controls, Preview/Back and same-instance Home/resume behavior verified
  on the release artifact.
- Offline settings, credits, media notices and checksum-verifying installer remain
  available without app network permissions, analytics or tracking.

## Verification

The exact tested signed APK is 121,223,466 bytes, SHA-256
`9541eb4fe2f4d7d69ac1f85b38144f5b5926274291ebec796d8150d27e07b781`,
with production certificate
`91128471b54e0c2cc28cb0400ebb5bd8e2b7f2509ba0b6d5ed0507f59752d5cf`.

AFTDEC012E/API 30 checks cover an in-place code 6 to code 7 update with all eleven
preferences preserved, actual D-pad selection of all three wood heights, white
frame widths, frameless wood, contrasting linear presets, Preview/Back and
same-instance resume. Normal non-test Hearth Dream activation occurred after
302.365 seconds under the unchanged five-minute timer and remained bound for
approximately 85 seconds before Back.

Three separate clean Preview windows observed 57.6915 to 58.1241 compositor
presents per second. Separated Dream windows near 20, 40 and 70 seconds observed
47.9996 to 57.6751 presents per second. These are not decoded-video frame rates,
continuous-duration timing or thermal results. The wood video is 30 fps; lively
playback runs at 1.25x. Recording was separate from timing. API 34 remote controls
and a 34.685-second movie received independent normal-speed review. Strict
physical cleanup preserved the launcher, OS, other apps/providers, external
files and protection/accessibility state.
